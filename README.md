\# IMU-Based Attitude Control Platform



A personal Electrical and Electronic Engineering project exploring inertial measurement, sensor calibration, orientation estimation, and feedback control using an Arduino-compatible microcontroller and an MPU-6500 IMU.



\## Goal



Design and test a one-axis attitude stabilisation platform capable of estimating its orientation and responding to external disturbances.



\## Current progress



\- Identified the IMU as an MPU-6500 using the `WHO\_AM\_I` register (`0x70`)

\- Experimentally mapped the X, Y, and Z accelerometer axes

\- Collected a six-position accelerometer dataset

\- Calculated initial accelerometer bias and scale calibration values



\## Current stage



Stage 1 — IMU characterisation and calibration.
